# Deep Learning Training Loops

This repository contains a simple, educational notebook focused on building a clear understanding of a standard PyTorch training loop.

## Purpose

`PyTorch.ipynb` was created to help me understand the core mechanics of training a neural network in vanilla PyTorch, without the abstraction layers of higher-level frameworks.

It walks through the essential steps:

- loading and transforming data
- defining a model
- choosing a loss function and optimizer
- running a training loop
- computing gradients with backpropagation
- updating model weights
- evaluating the model
- plotting training loss and accuracy
